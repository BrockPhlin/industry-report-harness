# 开题展示材料

当前版本：项目计划书v1.2、展示与演讲稿v0.9，日期2026-10-24。

- [可编辑PPTX](ppt/第11组_开题展示_v0.9.pptx)与[展示PDF](ppt/第11组_开题展示_v0.9.pdf)：共11页，全部为正式展示内容。
- [逐页演讲稿PDF](speech/第11组_开题演讲稿_v0.9.pdf)与[演讲稿Markdown](speech/演讲稿.md)：按PPT页码对应，包含讲述正文、指图提示和建议用时。
- [项目计划书PDF](report/第11组_项目计划书_v1.2.pdf)：9页；[报告源码](report/report.md)。
- [幻灯片与讲稿内容源](ppt/slides.json)：包含文字、原生图表位置、每页讲稿和来源。PPT备注中的讲述正文与独立演讲稿一致，资料链接不需要读出。

讲述按“给谁用—具体例子—使用流程—Harness—交付目标—任务估算—六人分工—进度—预算风险—验证”展开。第九页直接画开发顺序和并行工作，不显示活动代号、浮动计算或文件路径。封面单独列展示人郭润航。

计划讲述合计400秒，留20秒用于翻页和停顿；课程要求展示7分钟、问答3分钟。正式上台前需要实际计时彩排，根据语速调整停顿。字体与许可位于assets/fonts，跨设备先打开PDF核对版面。

光伏例子来自工信部与国家能源局；原型图为实际摘录运行截图，没有模型调用。Harness恢复、正式导出等为学期计划，不能讲成已实现。课程页码与公开来源分别在[课程映射](../../materials/课程内容映射.csv)、[来源记录](../../materials/references/research-notes.md)。

本次和学期分工分别见team/claims.csv、team/长期分工.md；详细任务在team/wbs.csv。工作目录仅保留当前稿及源码，旧稿从Git历史查看；新稿生成并视觉检查后再删除旧输出。
