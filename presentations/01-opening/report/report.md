# 3 技术方案与基线代码

### 3.1 架构与数据流

浏览器提交资料，HTTP接口检查请求，Service校验输入，Store保存SQLite。生成时读取所选原文，Generator执行确定性摘录或一次模型调用，保存Markdown与来源快照，页面显示结果并提供下载。

基线应用只用Python标准库，前端为静态HTML/CSS/JavaScript；业务与材料构建依赖分开。模型适配使用可配置的Chat Completions兼容接口，未配置时不回退成假模型结果。

### 3.2 当前能力与限制

| 组成 | 已初始化内容 | 后续增加 |
| --- | --- | --- |
| 资料层 | 原文、标题、机构、日期与来源，文本录入 | PDF解析、检索、更新、数据治理 |
| 生成层 | 摘录演示与单次模型适配 | 分章节检索生成、预算、引用门禁 |
| 业务层 | 报告保存、历史、来源快照、Markdown下载 | 审阅、版本、图表与正式导出 |
| 执行层 | 同步请求，出错明确返回 | Harness、检查点、恢复、有限重试 |

### 3.3 代码认领人的交付
