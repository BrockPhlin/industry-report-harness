\section*{原文核对（人工）}

\begin{itemize}
  \setlength{\itemsep}{0.35em}
  \item 组件产量 588 GW：原文“组件环节，1—12月全国产量达到588GW，同比增长13.5\%，出口量约238.8GW。”，与工具返回一致。
  \item 组件价格 −29.7\%：原文“全年主要光伏产品持续‘量增价减’态势，1—12月，多晶硅、组件价格分别同比下降39.5\%、29.7\%。”，负号表示同比下降，与工具返回一致。
  \item 新增装机 2.78 亿千瓦：原文“（三）光伏发电建设和运行情况。2024年，全国光伏新增装机2.78亿千瓦，同比增长28\%，其中集中式光伏1.59亿千瓦，分布式光伏1.18亿千瓦。”，与工具返回一致；开头综述另有一处“太阳能发电新增2.78亿千瓦”，为同一数值。
\end{itemize}

\section*{核验说明}

\begin{itemize}
  \setlength{\itemsep}{0.3em}
  \item 三项指标均由证据工具返回，且单一、齐全，无冲突、无缺失，本表没有“待核实”项。
  \item 单位与统计期与工具输出一致：价格单位为 \%（负号表示同比下降），装机统计期为 2024年。
  \item 2.78 亿千瓦按容量换算为 278 GW，仅用于说明单位口径，不改动原文数值。
  \item 链接口径以本表为准：工信部采用 wap.miit.gov.cn 官方页面，国家能源局采用 www.nea.gov.cn 官网页面。仓库早期材料（materials/references/research-notes.md、code/examples/public-sources.json、docs/T5代码交接与核验.md）中出现的 miit.gov.cn/dzxxs/dzjc 链接与 obor.nea.gov.cn 链接为旧链接或镜像转载，内容一致但地址不同，引用时建议统一为本表链接。
\end{itemize}
