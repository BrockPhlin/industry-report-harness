# 报告核查与资料修订

在已完成的联网研究报告中展开「核查正文与资料修订」。两项检查回答不同的问题。

- **逐句核查**回答“写报告时，这个数有依据吗？”系统只查本句所引的证据，按可识别的年份、地区、统计期、指标和单位核对数值。「数值有出入」列出冲突所在，「需人工判断」可展开原句和出处，供组员检查因果解释、排名或缺失的引用。「数值匹配」只确认规则识别到的量值。
- **资料修订**回答“当时引用的数后来变了吗？”系统将写作时留存的数值与本机同一取数地址、同一统计口径的最近快照比较。点击改值或缺项记录可看到前后取值及引用它的原句。比对时不会联网刷新。政策条文等文本资料跳过数值比对，旧记录缺少原始精度或单位变化时会显示「无法比对」。

生成章节时，`validate_draft` 会把明确的数值冲突退回修改。对于“融资条件决定了新增装机的变化”这样的解释，即使引用表格中的装机量完全正确，仍需有人检查资料能否支撑这个判断。

## 离线核对

在报告页分别点击「下载 Markdown」和「下载证据记录」，将同一版的两个文件放在一起。按仓库 README 安装 Python 依赖后，在仓库根目录运行以下命令。将 `report_dir` 改为实际下载目录。

```sh
report_dir="$HOME/Downloads"
.venv/bin/python code/pv_brief.py audit "$report_dir/solar-report.md" "$report_dir/pv-evidence.json"
```

命令校验正文的 SHA-256 指纹，输出逐句核查 JSON。若文件来自不同版本，请重新下载同一版的两个文件。资料修订需要本机数据库，可在网页查看并下载结果。以下命令只用仓库内的数据，在临时数据库重放评测，无需模型密钥。

```sh
.venv/bin/python tools/evaluate_research_review.py
```

## 定向评测

我们从国家能源局两张上半年分省表选取江西、湖北的集中式光伏新增和累计并网容量。只要把湖北的数字放在江西名下，数值仍出现在引用的表里，结论却已出错。这样的错配是本次评测专门检查的情形。[2025 年原表](https://www.nea.gov.cn/20250811/b32802d80ef04148b704e6bc1cd51eb2/c.html) · [2026 年原表](https://www.nea.gov.cn/20261113/49ccc766220c42e1a46719120952d1a3/c.html)

| 测什么 | 本地重放结果 |
| --- | --- |
| 3 条正确陈述 | 旧版 `855d09e` 误报 1 条，把“6月底”与“六月底”视作不同写法。当前写稿检查放行全部 3 条。 |
| 6 条植入错误 | 旧版拦下 3 条。当前写稿检查拦下 6 条，除漏负号、错单位和捏造数值外，也识别了错年、错省和把累计值写作新增值。 |
| 3 条需要人判断的陈述 | 缺出处、引用编号不存在、根据并网量推断融资原因，均列入「需人工判断」。 |
| 8 条观测的版本比较 | 原样入库时 8 条相同。在临时库将江西新增值由 −41.9 改为 −40.9 万千瓦、删去湖北一项累计值后，检出 1 项改值、1 项缺失、6 项相同。改值和缺行均由测试植入。 |

另用 IRENA 的中国光伏成本数据检查了 3 种表述。系统能匹配“平准化发电成本为 36 美元/MWh”，能找出把它写成售电成交价的错误，也会把“连续两年全球最低”交给人工核对。这组补测独立于上述 12 条陈述。要估计整份报告的事实准确率，还需要独立抽取更多报告并由研究人员标注。[IRENA 报告，摘要图 S3](https://www.irena.org/Publications/2026/Jul/Renewable-Power-Generation-Costs-in-2025)

## 设计参考

- ALCE 分别评价内容正确性与引用质量，DeepFact 以单条陈述为单位记录判断理由，并允许根据新证据修订判断。我们据此在界面并列展示原句、所引证据和判断理由，把规则难以判断的内容交给读者复核。[ALCE](https://aclanthology.org/2023.emnlp-main.398/) · [DeepFact](https://aclanthology.org/2026.acl-long.1586/)
- W3C 的数据版本建议要求说明数据版本及版本间的变化。项目保留写作时使用的快照指纹，让组员能追溯同一观测后来改了什么，并找到受影响的句子。[Data on the Web Best Practices，第 8.6 节](https://www.w3.org/TR/dwbp/#dataVersioning)
