# 原始选题与本期验收对应

日期：2026-10-26。对应计划书v1.6、展示v1.5；这是计划与设计说明，业务代码本次未改。

目标场景为政府智库、产业规划、行业研究。产业主题、数据来源与报告模板分开配置，构建可复用报告引擎；光伏及新能源汽车仅为验证输入。

| 原选题要求 | 计划能力与数据流 | 验收安排与失败处理 |
| --- | --- | --- |
| 模板体系 | 五类报告的章节、必填内容、风格可配置；模板版本随生成任务保存 | 首轮产业分析与对标两类完整流程；两个产业各至少3份资料复用流程。其余三类逐步扩展，不能宣称全部完成 |
| 长文本生成 | 资料及模板输入，先生成提纲，再逐章生成，记录输入版本和章节产物 | 检查章节覆盖、重复与前后矛盾；注入章节失败后保留成功结果并接续，输入变化使相关结果失效 |
| 数据、图表、溯源 | 指标记录包含值、对象、单位、时段和来源；正文与图表使用同一记录，观点关联证据 | 从真实输入自动生成至少一种图表；每份抽查至少5条关键表述，回查原文支持关系。资料不足明确提示，引用标签不代表事实正确 |
| 润色、导出、版本 | 原稿经公文风格润色和人工修订，保存原稿、修订稿与确认状态；导出引用当前版本 | 比较润色前后数字、观点与引用是否改变；Markdown及PDF或DOCX能读，中文、表格和分页可用。失败应报错，不以空文件当成功 |

Harness是上述业务流程的执行支撑，负责步骤状态、检查点及错误记录。模型承担内容生成，人负责需求、事实核对与最终确认。现有摘录原型和18项模拟响应基线测试不能证明上述目标已经实现。
