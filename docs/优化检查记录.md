## 可复现的响应体积测量

在仓库根目录运行：

```bash
python3 tools/measure_source_payload.py
```

脚本建立临时数据库，录入10份人工构造资料，每份正文为50000个“测”字。用同一数据库比较旧版全字段SQL结果与当前摘要列表，以ensure_ascii=False序列化后的UTF-8 JSON字节数为口径。原文和数据库不会进入团队资料库。

| 口径 | 字节数 |
| --- | ---: |
| 旧版全正文列表 | 1501730 |
| 本次摘要列表 | 1830 |

该构造输入的响应体积减少99.88%。这不是网络耗时、数据库查询速度或真实产业研究效果的测量；SQLite仍需计算正文长度，列表元数据也尚未分页。
