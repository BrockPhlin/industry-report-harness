# 模板参考与资源来源

字体和校名图像取自用户提供的参考文件，用途与许可如下。

- `fonts/LXGWWenKai-Regular.ttf`、`fonts/LXGWWenKai-Medium.ttf`：从参考文件同名字体目录复制，用于报告和幻灯片正文。
- `fonts/SmileySans-Oblique.ttf`：从参考文件复制，用于幻灯片标题。
- `brand/char_blue.png`、`brand/logo_blue.png`：参考文件中的浙江大学校名和校徽，限本次课程材料使用，保留原比例。

字体的原始许可见 `fonts/LICENSES.txt`。校名、校徽不声明为本项目原创或本项目开源授权内容。当前未为整个仓库选定开源许可证，公开发布前需确认团队授权和资源适用范围。
