# 国家能源局分省光伏并网统计

`utilization-annual.csv` 保存 2021—2025 年利用率。2021、2022 年取 2022 年国家能源局原报告表 6，2023、2024 年各取当年报告表 4；连续版本共同年份的地区行已逐项比对。2025 年取电力行业规划研究与监测预警中心发布表的年度列，来源站原图返回 404，取数地址为同一张表的转载图片。系统分别校验各原件指纹。蒙东和蒙西各成一列口径，按地区查询时分别展示。
