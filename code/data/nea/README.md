# 国家能源局分省光伏并网统计

这两份 CSV 对应国家能源局发布的 2024、2025 年度原表，单位均为万千瓦。录入六列数据，包括全年新增和年末累计，以及各自的集中式、分布式分项。户用子项未录入。空值表示原表空白。China 对应表内“总计”。

2024 年原表另列新疆兵团，2025 年原表只列新疆。跨年比较新疆时须保留这一口径差异。个别分项之和与合计的末位有出入，保留发布值。程序会联网取得官方原图、比对 SHA-256 指纹，再使用对应转录；图片变化后需复核。详见[2024 年原表](https://www.nea.gov.cn/20250221/f04452701c914d51a89d0c0ea6f4acd1/c.html)和[2025 年原表](https://www.nea.gov.cn/20260305/4216fa1274bd4b7f8da92090ba3999aa/c.html)。
