# IRENA 年度全球及分区光伏装机

`region-pv-2026.csv` 对应《Renewable Capacity Statistics 2026》PDF 第 37—40 页的地区汇总。列出全球及九个地区的 2016—2025 年纯光伏年末装机，单位 MW。入库时将 MW 换算为 GW，并校对原件 SHA-256。具体国家记录通过 IRENASTAT 的国家电力统计接口在线取数，保留各自的发布版本、并网和离网口径。
