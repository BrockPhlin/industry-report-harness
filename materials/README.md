本目录由开题 T4 崔大元维护，职责依据为 [本次任务与认领](../team/本次任务与认领.md) 和 [claims.csv](../team/claims.csv)。本次按用户指定完成课程映射；报告、PPT的润色和修改建议由其他成员完成，不计入本次成果。

## 交付入口

- [课程内容映射.csv](课程内容映射.csv)：**83条**，包括课件与课堂记录52条、选题说明9条、评分细则22条。逐项列出原意、项目采用方式、报告与PPT位置、证据、责任人、状态和验证安排。
- [T4课程映射说明.md](T4课程映射说明.md)：主要对应关系、报告/PPT索引、来源差异和交接边界。
- [来源索引.csv](来源索引.csv)：**15项文件记录**，含7份课件/课堂记录、选题及评分文件、1份同指纹选题副本和5份对照成品/内容源。
- [教师课件来源记录](course-slides/README.md) 和 [teacher-files.json](references/teacher-files.json)：本地原文件、授课日期依据、版本和定位方法。

对照成稿为 **项目计划书v1.2（9页）** 和 **开题展示v0.9（11页）**。

## 来源与页码约定

用户指定的 `course-slides` 目录现有原课件与课堂记录，已经读取。P4/P5的 SHA-256 与原仓库登记一致；补入的选题DOCX副本也与 `references` 中正式版本字节相同。来源可用性已按现状更新。

课件原文件随本分支一并提供，存放于 `course-slides`，包括7份课件/课堂记录和1份选题说明副本。来源索引中的路径相对仓库根目录，克隆仓库后即可按路径打开原文；文件内容保持原样，可用SHA-256核对版本。

**教师课件和本组展示的PPT页码均以页面右下角印出的页码为准，不能以PDF或PPTX中的顺序代替。** 例如P4写 `7 / 47`，P5写 `06 / 45`，开题展示写 `07 / 11`。课堂截图保留原幻灯片页码，截图重复或缺页也不重新编号。没有数字页码时写“未标数字页码”，使用页面标题及独有文字定位；课程介绍的星号页脚不当作数字页码。

报告使用印刷页码及章节号。DOCX使用章节标题、条目及辅助正文段落序号；Markdown使用章节锚点、评分编号和行号。来源索引中的文件页/张数仅用于完整性核对，不用于映射定位。

## 映射表怎么读

每条回答：老师原意或课程要求是什么、本项目具体采用什么、报告哪页哪节、展示哪个右下角页码、现有什么证据或将如何验证。

CSV保留原12列，增加 `source_type`、`source_id`、`verification_plan` 三列。`teacher_file` 为兼容原表保留的名称，对非课件行表示相应源文件；`file_version` 为完整SHA-256；`owner` 是项目应用责任人，表格维护人为T4。证据路径相对仓库根目录，多条路径以半角分号分隔。ID是条目标识，实际定位以 `page_or_slide` 和 `ppt_slide` 为准。

“原文已对照”表示来源与现稿位置已经核对；“计划待验证”“部分对应”“未采用”说明本组实际覆盖程度，不表示新增修改任务。方法的事后对应也不声称作者写稿时已直接采用该课件。映射完成不等于业务功能完成或获得评分确认。

9月28日课堂的旧评分口径与现行文件有差异，评分映射以 [课程报告与评分细则](references/课程报告与评分细则.md) 为依据，差异登记在 `C7-18`；提交日期仍按老师正式通知确认。原报告关于分享资料可用性的描述是成稿时状态，本次已用10月19日课堂记录补足分享出处。
