# 第11组中期执行计划

拟于11月30日展示，具体时间以课程通知为准。11月23日软工管课后由程文博组织讨论，确认本次光伏范围、验收和交接。组长程文博已明确担任本次主讲。任务实际负责人、交接时间及会议结论，以后续真实记录为准。

## 规划

使用开题已选的2024年光伏案例。研究员用一组公开历史统计生成一份简报，核对每个关键指标的出处，再确认导出。中期收敛到制造与价格、发电新增装机两章。新能源车、其他报告类型、更多模板留待后续评估。

| 拟牵头 | 按 Agent 工作分解 | 交接件 | 暂排 |
| --- | --- | --- | --- |
| 程文博 | 统筹、范围、验收与主讲 | 主持课后确认，组织组内复核联调证据并定稿完整讲稿并组织彩排 | 11/23、11/29 |
| 田亦洁 | 报告任务定义与设计 | 章节、必需指标、检查条件与系统设计报告 | 11/23 定范围，11/28 校稿 |
| 崔大元 | 证据工具 | 给出指标、来源、统计时段、计量单位，逐项核对引用位置 | 11/25 |
| 许子萌 | Agent 编排与模型适配 | 串起阶段和补查，核对 GLM 的工具返回与草稿结构 | 11/27 |
| 李佳雨 | 人工核对与模板导出 | 从草稿查看出处、修订可编辑文字并确认导出 | 11/27 |
| 郭润航 | 独立验证与演示保障 | 同源摘录对照、异常用例、演示环境与计时彩排 | 11/28 验证，11/29 彩排 |

一次可核对的交接可以围绕装机指标：证据工具交付包含时段、单位、发布机构与原文段落的条目，Agent 接口吃进同一结构，验证成员删除该来源复核流程并在同一任务记录附上真实 trace。记录合并链接、接收人和复核结果；现场使用完成的记录。

已有材料可从开题的[课程映射提交](https://github.com/BrockPhlin/industry-report-harness/commit/8dff737)和[公开样例与核验提交](https://github.com/BrockPhlin/industry-report-harness/commit/aafb9a2)回查。
